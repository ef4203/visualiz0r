# visualiz0r docs

A music visualizer for live shows. Open it in a browser, feed it audio, and it fills the screen with visuals that react to the volume, bass/mids/treble and beat. Put that screen on a projector, monitor or LED wall.

Runs locally in the browser. No account, no internet needed.

- [User guide](user-guide.md): get going in a minute
- [Display setups](display-setups.md): laptop to projector, monitor or LED wall
