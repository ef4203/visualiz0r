# Display setups

The projector, monitor or LED wall is just a second display. Set it to **Extend**, move the browser window onto it, press **F**. Your laptop screen stays free for DJ software.

| Mode       | Audience sees       | Use it when                                        |
| ---------- | ------------------- | -------------------------------------------------- |
| **Extend** | Only the visualizer | You perform and need your own screen (recommended) |
| **Mirror** | Same as the laptop  | Nothing else to do on the laptop                   |

```
 Laptop ──HDMI / USB-C──▶ Projector, monitor or LED processor
```

> The window must be on the external display _before_ you go full screen. If it opens on the wrong one, press **F**, drag the window across, press **F** again.

## Example 1: MacBook and projector (macOS)

1. Plug the projector into the MacBook (USB-C to HDMI adapter if needed) and select the right input on the projector.
2. **System Settings > Displays**, select the projector, **Use as: Extended Display**.
3. Set the projector to its native resolution (often 1920x1080).
4. Open Chrome, go to <http://localhost:5173>, connect audio.
5. Drag the window onto the projector and click **Start visualizer**.
6. Turn on Do Not Disturb.

## Example 2: Windows laptop and external monitor

1. Connect the monitor (HDMI, DisplayPort or USB-C) and select its input.
2. Press **Windows + P**, choose **Extend**.
3. **Settings > System > Display**: drag the screens to match their physical position.
4. Open Chrome or Edge, go to <http://localhost:5173>, connect audio.
5. Drag the window onto the monitor and click **Start visualizer**.
6. Turn on Focus Assist.

## Example 3: Laptop to an LED wall

The laptop connects to the wall's video processor (Novastar, Colorlight, etc.), not to the panels.

```
 Laptop ──HDMI/DP──▶ LED processor ──Ethernet──▶ LED panels
```

1. Connect the laptop to the processor's HDMI or DisplayPort input.
2. Set the laptop to **Extend** at the processor's input resolution (usually 1920x1080).
3. Ask the technician to match the processor to the wall's size and aspect ratio. The visuals adapt to any screen shape.
4. Drag the window to the LED display and press **F**.

LED walls are very bright up close, so ask for dimming in small rooms. Prefer calmer visuals for long sessions.
